## 💎 Feature Deep-Dive (Marketing Perspective)

### 1. 🛡️ Privacy by Design: 100% On-Device Intelligence
- **Marketing Narrative**: Protect candidate trust and exceed global privacy regulations (GDPR, CCPA, EU AI Act). EdgeTal converts your smartphone or tablet into a self-contained AI recruiter. Resume text, personal identifiers, and search history remain 100% inside your device sandbox.
- **Key Value Proposition**: Zero cloud liability. No third-party servers to audit, breach, or compromise.

### 2. 🧠 Explainable On-Device Candidate Fit Analysis (Gemma-2B IT)
- **Marketing Narrative**: Stop relying on black-box match scores. EdgeTal runs Google's Gemma-2B LLM directly on your mobile hardware to deliver structured, explainable hiring intelligence:
  - 💭 **Thought Process**: Step-by-step reasoning on how candidate experience maps to your Job Role.
  - 📑 **Evidence Extraction**: Verifiable quotes and skill achievements pulled from the candidate's CV.
  - 📌 **Verdict & Skill Gaps**: Clear hiring recommendation (**Yes**, **Maybe**, **No**) with missing skill callouts.
- **Key Value Proposition**: Instant, transparent candidate scoring without per-token cloud API bills.

### 3. 🔍 Sub-100ms Hybrid Semantic & Keyword Vector Search
- **Marketing Narrative**: Find exact talent in seconds using natural phrasing (e.g., *"Senior Full-Stack Engineer with Flutter, Microservices, and high-scale Postgres experience"*).
- **Key Value Proposition**: Combines 512-dimensional MediaPipe vector embeddings with exact keyword highlighting so you never miss a candidate due to formatting variations.

### 4. 📁 Multi-Source Resume Ingestion Pipeline
- **Marketing Narrative**: Seamlessly import candidate datasets from local folders, cloud drives (Google Drive, iCloud, OneDrive), or structured CSV files/links in minutes.
- **Key Value Proposition**: Converts raw PDF, DOCX, and text files into vectorized candidate profiles automatically.

### 5. 🎯 Integrated Job Roles & 3-Tab Candidate Pipeline Management
- **Marketing Narrative**: Create targeted Job Roles with required competencies, location, and job descriptions. Rank candidates in real-time and drag them across your recruitment pipeline (*Shortlisted*, *Interviewing*, *Offer*, *Placed*).
- **Key Value Proposition**: Streamlined pipeline visualization directly connected to your local vector database.

### 6. 🔒 Vault Lock & Encrypted Peer-to-Peer Package Sharing
- **Marketing Narrative**: Protect your physical device with PIN passcode and Face ID / Touch ID lock (`AppLockService`). Share candidate shortlists across recruiting team members using password-encrypted `.edgetal` backup archives over AirDrop, email, or USB.
- **Key Value Proposition**: Enterprise-grade local security with seamless peer-to-peer sharing.

## 📖 Step-by-Step Onboarding Guide: "How to Use EdgeTal"

```mermaid
graph LR
    Step1["1. Import Resumes (PDF / DOCX / CSV)"] --> Step2["2. Create Job Role & Skills"]
    Step2 --> Step3["3. Run Semantic Vector Search"]
    Step3 --> Step4["4. Execute On-Device LLM Fit Analysis"]
    Step4 --> Step5["5. Move Candidates in Pipeline"]
```

### Step 1: Import Candidates in Seconds
Open the **Import Screen**, tap **From Folder** or **CSV Import**, and select your resume files. EdgeTal automatically extracts candidate names, emails, raw text, and generates 512-dimensional vector embeddings on-device.

### Step 2: Create Open Job Roles
Navigate to **Jobs & Pipelines**, tap **+ New Job**, and paste your job description along with required skills. EdgeTal instantly generates a job vector representation.

### Step 3: Run Natural Language Talent Searches
Type what you need in the **Search Bar** using everyday language. View instant candidate match percentages ranked by dense semantic similarity.

### Step 4: Run On-Device AI Fit Rationale
Tap any candidate card, open **AI Fit Analysis**, select your target **Job Role**, and tap **Run Fit Analysis**. Watch Gemma-2B analyze candidate suitability in real-time—100% offline.

### Step 5: Manage Pipeline & Share Securely
Assign candidates to pipeline stages (*Shortlisted* $\rightarrow$ *Placed*). When sharing candidate pools with team members, export a password-encrypted `.edgetal` package from **Backup & Export**.
